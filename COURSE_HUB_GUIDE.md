## 🚨 TROUBLESHOOTING

### Server won't start
```bash
# Make sure venv is activated
.\venv\Scripts\activate

# Delete db.sqlite3 and run migrations
rm db.sqlite3
python manage.py migrate
```

### "No module named django"
```bash
# Reinstall packages
pip install -r requirements-venv.txt
```

### Port 8000 already in use
```bash
# Use different port
python manage.py runserver 8001
```

### Admin login not working
```bash
# Reset admin password
python manage.py changepassword admin
```

## 🎯 PRODUCTION DEPLOYMENT

When ready to deploy:

1. **Update settings.py**
   ```python
   DEBUG = False
   ALLOWED_HOSTS = ['yourdomain.com']
   ```

2. **Collect static files**
   ```bash
   python manage.py collectstatic
   ```

3. **Use production server**
   ```bash
   gunicorn myproject.wsgi:application
   ```

4. **Use proper database** (PostgreSQL recommended)

5. **Setup SSL/HTTPS** (Let's Encrypt)

## 📞 SUPPORT

### Common Issues

**Admin panel shows no data:**
- Run `python manage.py migrate`
- Check if seed data was loaded

**Images not showing:**
- Ensure MEDIA_ROOT and MEDIA_URL configured
- File permissions are correct

**Search not working:**
- Check database connection
- Verify migrations applied
